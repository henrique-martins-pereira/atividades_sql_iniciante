# 📊 SQL Portfolio — Samsung Commerce

Repositório de estudos criado para praticar SQL e registrar minha evolução em consultas e análise de dados. O projeto utiliza um banco de dados SQLite de uma loja fictícia inspirada no comércio de produtos Samsung.

> 🎯 **Objetivo:** desenvolver raciocínio analítico, aprender a consultar e relacionar dados e transformar informações em indicadores de negócio.

## 🧠 Sobre o projeto

O repositório reúne **20 atividades SQL**, divididas em duas etapas de dificuldade e temas.

Este é um projeto de aprendizado: as consultas representam meu processo de evolução e podem passar por revisões, correções e melhorias.

## 🧩 Etapas das atividades

| Etapa | Conteúdo | Atividades |
|---|---|---|
| 01 | Análise de vendas | 01–10 |
| 02 | Produtos e categorias | 11–20 |

## 🛠️ Tecnologias e ferramentas

- **SQL** — linguagem utilizada nas consultas e análises.
- **SQLite** — sistema de banco de dados utilizado no projeto.
- **DB Browser for SQLite** ou **VS Code** — opções para abrir o banco e executar consultas.

## 🗃️ Banco de dados

O banco contém sete tabelas principais:

- `clientes`
- `funcionarios`
- `categorias`
- `produtos`
- `vendas`
- `itens_venda`
- `pagamentos`

## ▶️ Como utilizar

1. Clone ou baixe este repositório.
2. Abra o banco `loja_samsung.db` em uma ferramenta compatível com SQLite.
3. Consulte os enunciados no arquivo `atividades_sql.sql`.
4. Resolva os exercícios utilizando SQL.
5. Salve suas consultas em arquivos `.sql`, organizados por etapa.

### Clonar o repositório

```bash
git clone https://github.com/henrique-martins-pereira/atividades_sql_iniciante
```

## 📚 Conteúdos praticados

- `SELECT`, `WHERE`, `ORDER BY` e `LIMIT`;
- `JOIN` e relacionamentos entre tabelas;
- `GROUP BY`, `HAVING` e funções de agregação;
- cálculos de faturamento, descontos, receita líquida e ticket médio;
- CTEs (`WITH`);
- funções de janela, como `AVG() OVER()`, `SUM() OVER()`, `LAG()`, `ROW_NUMBER()` e `DENSE_RANK()`.

## ⚠️ Sobre as soluções

As consultas registradas são minhas tentativas durante o aprendizado. Algumas ainda podem precisar de ajustes de lógica, sintaxe ou desempenho. Manter esse histórico faz parte da proposta do projeto: documentar o que estou aprendendo e aprimorar minhas habilidades em SQL.
